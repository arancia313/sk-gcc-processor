A software for the PSP (PlayStation Portable)
for using SK-GCC, the famous important component for the A3N.

## Requirements

Requires the very latest version of ARK-4 A3
found in the pinned repos.

#### Features

- Includes a tool called "Le Straodinarie" (The Extraodinaries), to abbreviate `ls`,
allowing to reset exh or SK-GCC corrupt configurations.
